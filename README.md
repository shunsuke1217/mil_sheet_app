# ミルシート読み取り

スキャンしたミルシート（鋼材検査証明書）の PDF フォルダを Gemini で読み取り、
品名順・サイズ順に並べた xlsx と、同じ順に並べ替えて 1 つにまとめた PDF を作るデスクトップアプリです。
仕様は [SPEC.md](SPEC.md) を見てください。

## 使い始めの準備（最初に 1 回）

### 1. 単重マスタのスプレッドシートを作る

1. アプリの「設定」→「初期マスタを CSV で書き出す」で CSV（225 件）を保存する
2. Google スプレッドシートを新しく作り、「ファイル → インポート」でその CSV を読み込む
   （1 行目が `品名 / サイズ / 単重` の見出しになっていること）
3. 右上の「共有」→「一般的なアクセス」を **「リンクを知っている全員」・「閲覧者」** にする
   - アプリはログイン無しで読むため、この共有設定が必要です（会社の Workspace で社外への共有が禁止されている場合は使えません）
   - API キーや Google Cloud の設定は不要です
4. 単重のタブを開いた状態で、ブラウザのアドレス欄の URL をコピーする（末尾に `#gid=…` が付いていれば、そのタブを読みます）

単重の追加・変更・削除は、このスプレッドシートを直接編集します。アプリは読むだけです。

### 2. Gemini の API キーを用意する

- [Google AI Studio](https://aistudio.google.com/) で API キーを作る
- **課金を設定したプロジェクトのキーを使ってください。** 無料枠では、送ったデータが学習に使われる可能性があります
  （課金が設定されていないかどうかはアプリからは判定できません）

### 3. アプリの設定画面に入力する

「設定」に、Gemini の API キーとスプレッドシートの URL を入れて保存します。
「接続を確かめる」で件数が表示されれば準備完了です。API キーは Windows の資格情報マネージャー / Mac のキーチェーンに保存され、ファイルには書かれません。

## 使い方

1. PDF の入ったフォルダを枠にドロップする（または「フォルダを選ぶ」）
2. 出力先の xlsx を確かめて「読み取りを実行」
3. 終わると `X.xlsx`・`X.pdf`（並べ替えてまとめた PDF）・`X.json`・`X_raw.json` が同じフォルダにできる
4. 要確認の一覧を見て、必要ならスプレッドシートに単重を足し、「マスタを読み直して作り直す」を押す（Gemini は呼び直さないので追加の課金はありません）

一度読み取ったページはキャッシュされるので、同じ PDF をもう一度読み取っても課金されません。

## 開発

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/pytest -q
.venv/bin/python main.py
```

- サンプル PDF（`tests/fixtures/20261014084620.pdf`）は社外秘のためリポジトリに入れていません。無いときは PDF を使うテストが skip されます。
  ルートに元データがあれば `.venv/bin/python scripts/convert_fixtures.py` で作れます
- 実 API のテスト: `GEMINI_API_KEY=... .venv/bin/pytest tests/test_extract_live.py -s`（サンプル 10 ページの一致率を表示）
- ログ: データ用フォルダの `logs/app.log`（Mac: `~/Library/Application Support/ミルシート読み取り/`、Windows: `%APPDATA%\ミルシート読み取り\`）

## 配布

`v1.0.0` のようなタグを push すると、GitHub Actions が Windows 用（exe 1 つ）と Mac 用（.app の zip）をビルドします。
Actions の画面から手動でも実行できます。成果物は各実行の「Artifacts」からダウンロードします。

署名をしていないため、初回起動時に警告が出ます。

- Windows: SmartScreen の「詳細情報 → 実行」
- Mac: アプリを右クリック →「開く」

**注意:** ミルシートの PDF・Excel などの元データは社外秘です。GitHub に push する前に、リポジトリに含まれていないことを確かめてください。
